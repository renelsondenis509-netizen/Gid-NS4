Politique de Confidentialité

Dernière mise à jour : 17 juin 2026

📋

1. Introduction

Gid NS4 (aussi appelé Prof Lakay) est une application mobile éducative destinée aux élèves haïtiens préparant l'examen national NS4 (Baccalauréat). Cette politique explique quelles données nous collectons, pourquoi, et comment nous les protégeons.

En utilisant l'application, vous acceptez les pratiques décrites dans cette politique.
🗂️

2. Données collectées

  • Nom complet — pour personnaliser l'expérience dans l'application
  • Numéro de téléphone — utilisé comme identifiant unique (jamais partagé)
  • Code établissement — pour associer l'élève à son école
  • Historique des questions posées — stocké localement sur l'appareil
  • Scores de quiz — sauvegardés dans notre base de données pour le classement
  • Images scannées — traitées par l'IA et non stockées de façon permanente
⚠️ Nous ne collectons jamais de données financières, de mots de passe, ni d'informations de géolocalisation.
🎯

3. Utilisation des données

Les données collectées sont utilisées exclusivement pour :

  • Authentifier l'élève et associer son compte à son établissement
  • Générer des réponses pédagogiques personnalisées via l'IA
  • Afficher le classement anonymisé (numéros masqués)
  • Calculer les statistiques d'utilisation de l'établissement (tableau de bord directeur)
  • Améliorer la qualité du service
🤝

4. Partage des données

Nous ne vendons, ne louons, ni ne partageons vos données personnelles avec des tiers à des fins commerciales.

  • Fournisseurs d'IA Uniquement le contenu de vos questions, sans données d'identification
  • Supabase — hébergement sécurisé de la base de données (serveurs chiffrés)
  • Directeurs d'établissement — statistiques agrégées uniquement (pas de données individuelles identifiables)
🔒

5. Sécurité des données

  • Toutes les communications sont chiffrées via HTTPS/TLS
  • Les clés API sont stockées comme secrets côté serveur (jamais exposées)
  • Les numéros de téléphone sont masqués dans les classements publics
  • L'accès aux données est restreint par des politiques Row Level Security (RLS) dans Supabase
👶

6. Mineurs

Gid NS4 est destiné aux élèves de NS4 (généralement 18–20 ans). Pour les utilisateurs mineurs, nous recommandons l'approbation parentale avant utilisation. Nous ne collectons pas sciemment de données sur des enfants de moins de 13 ans.

✅

7. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles stockées
  • Demander la correction de données inexactes
  • Demander la suppression de votre compte et données associées
  • Retirer votre consentement à tout moment en cessant d'utiliser l'application
Pour exercer ces droits, contactez-nous à l'adresse ci-dessous.
🗃️

8. Conservation des données

Les données de profil et scores sont conservés tant que le compte est actif. En cas d'inactivité de plus de 10 mois ou sur demande, les données sont supprimées. L'historique local (sur l'appareil) peut être effacé depuis l'application à tout moment.

🔄

9. Modifications de cette politique

Cette politique peut être mise à jour. En cas de modification substantielle, une notification sera affichée dans l'application. La date de dernière mise à jour est toujours indiquée en haut de ce document.

Une question sur vos données ?
